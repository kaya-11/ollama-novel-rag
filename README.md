# ollama-novel-rag

> **A test/learning project: RAG (Retrieval-Augmented Generation) with Ollama, Chroma, and novels.**

---

## What is this?

An **experimental project** to learn and test **Retrieval-Augmented Generation (RAG)** using:
- **Ollama** for local LLM embeddings and text generation.
- **ChromaDB** as a vector database to store and retrieve text chunks.
- **LangChain** for document loading and text splitting.

⚠️ **Note:** This is **not a production project** – it's a **learning and testing environment** for understanding RAG workflows.

---

## Features

- **Load and process texts**: Convert PDFs to Markdown and split novels into chunks.
- **Generate embeddings**: Use Ollama to create semantic embeddings for text sections.
- **Store in ChromaDB**: Persist embeddings and text chunks for efficient retrieval.
- **Query and generate**: Ask questions about the text and get answers generated by Ollama.

---

## Requirements

- **Python 3.10+**
- **[Ollama](https://github.com/ollama/ollama)** (locally installed, e.g., `ollama pull llama3.2`)
- **ChromaDB** (`pip install chromadb`)
- **LangChain** (`pip install langchain-community`)
- **Additional dependencies** (see `requirements.txt`)

## Quick Start

### 1. Clone the Repository
```bash
git clone https://github.com/kaya-11/ollama-novel-rag.git
cd ollama-novel-rag
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Set Up Environment Variables
Create a `.env` file in the root directory with the following variables:
```env
NOVEL_NAME=your_novel_name
CHROMA_PATH=./chroma_db
DATA_PATH=./data
```

### 4. Start Ollama
Ensure Ollama is running and a model is loaded:
```bash
ollama serve
ollama pull llama3.2  # or another model like mistral
```

## Workflow

### Step 1: Prepare Your Text
1. Place your novel or text file (PDF or Markdown) in the `data/` directory.
2. If your text is a PDF, convert it to Markdown:
   ```bash
   python pdf2md.py
   ```

### Step 2: Create the Vector Database
Run the script to load, chunk, and embed your text into ChromaDB:
```bash
python create_database.py
```
This script:
- Loads documents from `DATA_PATH` (default: `./data`).
- Splits them into chunks (default: 1000 tokens, overlap: 500).
- Generates embeddings using `OllamaEmbeddingFunction.py`.
- Saves everything to `CHROMA_PATH` (default: `./chroma_db`).

### Step 3: Query the Database
Ask questions about your text:
```bash
python query_data.py
```
Example output:
- Input: `What kind of character is Holden's roommate Stradlater?`
- Output: A generated answer based on the retrieved context.

## Customization

### Change the Model
Edit `OllamaEmbeddingFunction.py` to use a different Ollama model:
```python
# Example: Switch from llama3.2 to mistral
response = ollama.embeddings(model='mistral', prompt=text_to_embed)
```

### Adjust Chunking
Modify `create_database.py` to change chunk size or overlap:
```python
text_splitter = RecursiveCharacterTextSplitter(
    chunk_size=800,       # Default: 1000
    chunk_overlap=200,    # Default: 500
)
```

### Modify the Prompt Template
Edit the prompt in `query_data.py` to change how answers are generated:
```python
PROMPT_TEMPLATE = '''
You are an expert about the novel {NOVEL_NAME}. Use the following context to answer the question:

{context}

---
Answer the question in up to 3 sentences using the context above: {question}
'''
```
